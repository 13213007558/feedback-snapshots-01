Add the optional `:agent_signing_authorization` hook, which is called with the verified target (host, host key and fingerprint), session id and key exchange, selected public key, purpose and signature algorithm for every ssh-agent signature request, and decides whether the agent may sign. The agent is never asked to sign before the current key exchange's host key has been verified, a rekey or retried authentication presents the new exchange's target, and a refused key is skipped like any other refused identity. It contains no private key or signing material, and it does not restrict remote agent forwarding.
