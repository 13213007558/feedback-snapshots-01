3.1.0
=====

Additions
---------

* Added :attr:`~pynetdicom.ae.ApplicationEntity.deidentifier` so a deployment
  supplied de-identification operation can be applied to outgoing datasets
  before they're encoded, covering both direct C-STORE requests and the
  C-STORE sub-operations generated by the Query/Retrieve SCP. Failures raise
  :class:`~pynetdicom.DeidentificationError` and are included in the C-GET and
  C-MOVE response summaries.

Fixes
-----

* Fixed the default logging handlers for N-ACTION treating *Action Type ID* as mandatory (:issue:`1027`)
* Fixed being unable to resolve IPv4 address when using the hostname (:issue:`1033`, :pr:`1034`)
* Fixed the socket not being closed when shutting it down fails (:issue:`1102`)
