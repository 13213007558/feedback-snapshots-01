Add ``--system-site-packages-allow`` and ``--system-site-packages-dir`` to inherit only the named top-level packages of
the parent interpreter's system site-packages. The approved names resolve through a runtime gate written into the
environment, so the parent directories stay off ``sys.path``, an interpreter start and ``activate_this.py`` see the same
set, and the scope is recorded in ``pyvenv.cfg`` and a JSON manifest. ``--system-site-packages`` keeps exposing every
system package.
