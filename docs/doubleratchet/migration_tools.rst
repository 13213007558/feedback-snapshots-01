Module: migration_tools
=======================

Verifiable, lossless migration of pre-stable Double Ratchet JSON state, with a read-only preflight check and
safe on-disk migration that never fabricates missing keys and never logs secret material. Refer to
:ref:`serialization_and_migration` for the workflow and the list of conditions under which a lossless
migration is not possible.
